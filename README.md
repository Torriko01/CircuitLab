# 电路直觉实验室 · MVP 0.5

面向嵌入式软件工程师的本地交互式学习工具。十二个案例：分压带载、RC、I²C、GPIO、供电瞬态、ADC、MOSFET、感性续流、PCB 回流、按键与迟滞、运放缓冲与饱和、SPI 采样。每课均有预测、真实电路仿真、虚拟测量、两个故障挑战、迁移题和复盘。

新增“自由实验室”：原生绘图编辑器、中文项目工作台、本机自动保存、文件备份和原生示波器。可从空白画图，或复制前三课正常实验的当前参数继续分析。课程内容仍为 0.4，课程进度格式仍为 schema 4。

当前范围与学习路线见 [课程能力矩阵](./docs/项目进展与课程能力矩阵.md)；沙盒的实际支持范围、数值和操作证据见 [v0.5 验收报告](./docs/沙盒验收报告-v0.5.md)。

## 直接运行

ZIP 交付包包含构建好的 `dist/` 和本地 CircuitJS 资源。使用交付包时，安装 Node.js 后即可运行，不需要 Java，也不需要先安装前端依赖。建议 Node.js 24 或更新版本；本机验证版本为 26.7.0。

在本目录执行：

```sh
npm start
```

然后打开 [本地实验室](http://127.0.0.1:4173/)。按 `Ctrl+C` 停止。本机 macOS 也可在 Finder 中双击 `启动实验室.command`，它会启动服务并打开浏览器。

从 Git 检出源码后，先安装依赖并生成运行包，再启动：

```sh
npm ci
npm run build
npm start
```

Git 保留固定内核资源 `public/vendor/circuitjs/`，首次构建不必重新构建内核。`dist/`、本机缓存和 `releases/` 中的 ZIP 不纳入版本控制；现有交付包保留在本地，校验清单纳入 Git。文件分类见 [仓库文件与版本管理约定](./docs/仓库文件与版本管理约定.md)。

服务只监听 `127.0.0.1`，没有线上发布。端口冲突时，例如：

```sh
CIRCUIT_LAB_PORT=4174 npm start
```

不要双击 `dist/index.html` 作为文件打开；仿真器需要通过同源 HTTP 页面运行。

## 第一次怎样学

1. 从“分压与负载”开始，读任务，先提交预测；不确定也可以继续。
2. 改一个参数，观察电路和捕获波形。可以拖动游标，或慢放已经捕获的波形。
3. 选择测量目的和测点，保存证据。电压始终是红端减黑端；支路电流按声明方向。
4. 进入诊断，选择挑战 A/B。根据证据判断原因，再回答迁移题。
5. 写下一句话复盘，保存学习记录。完成流程与独立掌握是两回事，成绩和提示使用另列。

诊断模式隐藏实际故障参数，保留可观察的现象。默认先做挑战 A，可切换 B；“重新学习”会重置当前流程，保留已有证据。不要把当前题的原因仅凭一个异常读数认定。

学习记录保存在当前浏览器的 localStorage，可导出/导入 JSON，文件上限 4 MB。0.1/0.2/0.3 的旧记录会分别备份并迁移到 schema 4；原进度、测量与证据来源版本保留，新课程从头开始。不同浏览器、主机名或端口不共享记录；长期学习建议固定使用 `http://127.0.0.1:4173/`，并定期导出。导入失败不会覆盖现有记录。原始高精度波形保留在内存，刷新后重新捕获。

## 能力与模型边界

自由实验室的起步、绘图、观察和保存步骤见 [使用指南](./docs/自由实验室使用指南-v0.5.md)。选择空白、分压、RC 或开漏模板，用原生工具栏放元件连线，右键元件编辑或加入示波器。重点验证基础 R/C/L、源、导线、地、开关、二极管和受控开关；其他原生器件可探索，需核对其具体模型。

沙盒自动保存于独立 IndexedDB，支持项目 JSON 和原生 XML 文件备份、导入新副本。重开从显式初始条件开始并暂停，不恢复历史曲线或运行断点。改连接/参数后须重新开始；开关可以作为连续激励。最多运行 200 个图元，每段连续运行 60 秒后暂停，可继续。多窗口冲突或存储失败时保留内存编辑并提示下载或另存。

- 分压：接入/移除负载、成对修改分压电阻、双端电压与支路电流、功率。
- RC：阶跃或 2/10/30 ms 脉冲、R/C 预设、峰值与门限时间。
- I²C：上拉/电容/100 与 400 kHz 预设、30%–70% 上升时间、稳定低态电压和电流。
- GPIO：推挽/开漏/输入高阻、有限驱动、上下拉、负载移除与接收区域。
- 供电：路径电阻、局部电容、脉冲/持续电阻负载、最低电压与观察线越界时长。
- ADC：显式采样开关与保持电容、源阻抗、采样窗口、前次状态、实际参考及理想数字码。
- MOSFET：栅源参考、原生非线性沟道、负载线工作点、路径与漏源压降、直流功耗。
- 感性负载：R-L 线圈、二极管与理想吸收支路、独立电流波形、开关峰值、10% 衰减时间。
- PCB：预制共用/独立回流接法、等效路径电阻、传感器参考地差与同一时刻的三电压取证。
- 按键：预制反跳、R-C、单/双门限；比较多计、漏计与响应延迟。
- 运放：1 倍缓冲或 2/3 倍同相放大、有限增益和输出软限幅；两档输入区分反馈比例与饱和。
- SPI：数据路径 R-C、实际采样事件、改变至采样间隔、50 ns 建立/50 ns 保持的教学窗口。
- 测量练习：分压的 1/10 MΩ 仪表负载，I²C 的 10/100 pF 探头电容。
- 诊断：十二案例各两种原因，共 24 个诊断挑战、24 道迁移题；新增课程要求多项证据，单一异常不足以获得完整分析评价。

模拟读数与波形来自固定版本 CircuitJS 求解；数字码、功率等按公开规则从同一次运行数据派生。独立电路解析公式仅用于测试基线与精度规划。波形慢放回放已有样本，不改变仿真时间和求解精度。

I²C 仅模拟一根开漏线的周期性拉低/释放，不执行真实协议帧。100 Ω 是教学导通电阻，3 mA 和 0.4 V 是能力检查假设，不能用它预测实际器件超额后的限流、温升或损坏。课程中的逻辑门限也不能代替目标芯片手册。

PCB 课是预制连接与集中参数模型，不做电磁场、自动布线或电流密度分析；低频回流示例不能推导成通用割地规则。MOSFET 不含热和开关寄生，感性课的吸收电压源不是真实 TVS 器件。实际硬件工作仍需手册与实测。本版没有固件联合仿真、PCB 编辑和账号。

按键输入为预制情境，迟滞不等于任意时长的时间去抖。运放没有输入共模、带宽、压摆率、输出限流或动态稳定性模型。SPI 只检查单数据路径的三个事件，不解码帧；窗口和门限均为教学假设，不能据此保证真实通信。

## 开发与验证

```sh
npm ci
npm run dev
npm test
npm run build
```

开发服务默认 `http://127.0.0.1:5173/`；它与直接运行的 4173 端口具有独立学习记录。

固定内核已经构建在 `public/vendor/circuitjs/`。如需从随附源码重建：

```sh
npm run build:engine
npm run build
```

该操作从 `vendor/circuitjs/source.tar.gz` 解压固定源代码，使用 Node/Vite 构建；不需要联网重新下载源码。构建产物记录在 `public/vendor/circuitjs/provenance.json`。没有修改数值求解算法；构建关闭上游 Service Worker、调整启动注册顺序，并注入可复现的沙盒桥接。具体变更见 [第三方来源](./docs/第三方来源.md)。

开发专用 [核验页](http://127.0.0.1:5173/probe.html) 不包含在生产运行包入口中。在该页浏览器控制台执行：

```js
await probeRun('divider', { connected: true })
await probeRun('rc', { pulse: 0.002 })
await probeRun('i2c')
await verifyEngine()
await verifyExtensions()
await verifyStages()
await verifySignals()
```

`verifyEngine()`：67 次捕获、102 项检查。`verifyExtensions()`：345 次、1189 项。`verifyStages()`：226 次、1146 项。`verifySignals()`：259 次、2044 项，覆盖反跳/迟滞、运放静态范围、SPI 采样窗口与步长减半。四套合计 897 次捕获、4481 项检查已在 v0.5 内核重新执行并全部通过；46 项单元检查通过。核验过程需要保持标签页活动。

沙盒内核在 Chromium/WebKit 各通过 33 项，手绘与文件闭环各 6 项，操作与恢复各 17 项；菜单/课程复制 14 项、课程生产回归 26 项及实际 60 秒运行预算通过。课程固定模型的通过不代表任意沙盒电路已验证。

数值核验以独立节点分析和一阶瞬态公式为参考；ADC 保持电压预设矩阵容差为 4 mV，不用于亚 LSB 级芯片精度验证。供电课为 R+C 电路，没有 ESR/ESL、稳压器环路或实际 BOR 模型。课程读数通过不表示某款真实器件或 PCB 已完成设计验证。
