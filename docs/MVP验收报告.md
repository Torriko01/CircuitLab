## 2. 技术预研结论（G0）

原候选 Java/GWT 构建在本机没有 Java 运行时。进一步核对官方发布流水线后，选用固定提交 `8ee04b18a6c9241675f1c4f766617806c2fe148d` 的 TypeScript 移植源码，使用 Node/Vite 构建，保留原有 JS 接口。

已经实际验证：本地同源加载、节点标签、电阻支路电流、仿真时间、最大步长、逐步回调、捕获结束停止、模板重载/硬复位与初始电容状态。

期间发现并修正了教学开关控制端坐标，之后完成 I²C 低态、释放边沿及收敛检查。没有修改上游数值求解算法；原始源码、构建方式和许可证随项目保存。

## 5. 与草案的实现细化

- 固定内核优先使用官方 TypeScript 移植，避免要求用户安装 Java；版本与源代码可追踪。
- 课程使用类型化 TypeScript 数据，暂未拆成独立 JSON 文件；电路参数和用户记录有运行时校验。
- 教学参数使用有限预设，改变后从初始条件重新求解；没有通用元件实时修改接口。
- 节点/支路选择代替拖拽探针；原理图禁止编辑，避免诊断中泄露真实参数。
- 分压中“移除模块”用实际开关断开支路；高阻模块的诊断仍用 1 TΩ 教学近似。
- 回放操作只移动已捕获波形的游标。原理图与波形的时间含义已分别标注。
- 自动规则评价主要用结构化选项与所选证据；不会声称理解任意自由文本。

## 7. 已知边界和下一步

- 仅固定教学电路与预设，不能替代通用 EDA 或器件级设计验证。
- I²C 不执行真实协议，100 Ω/3 mA/0.4 V 为明确教学假设。
- 不包含 PCB、MCU 固件执行、任意电路导入和云端同步。
- 页面自动保存最近流程与证据；高精度波形在内存中，刷新需要重新捕获。
- 单人试学、延迟复测、手册/实物迁移与真实 Safari 使用体验待用户验证。

建议先做分压案例，重点观察自己能否说明测量目的；然后做 RC 与 I²C。若迁移题仍有困难，先调整引导与案例，不急于扩充课程数量。
