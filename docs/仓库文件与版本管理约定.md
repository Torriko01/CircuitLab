# 仓库文件与版本管理约定

日期：2026-10-16。适用于当前 MVP 0.5 源码仓库。

## 文件分类

| 路径 | 内容 | 版本控制 |
|---|---|---|
| `src/` | 工作台、课程、仿真适配、沙盒与样式 | 纳入 Git |
| `engine-overrides/` | 可复现的原生内核桥接覆盖文件 | 纳入 Git |
| `scripts/`、`tests/`、`probe.html` | 构建、服务、验收脚本、单元测试和开发核验页 | 纳入 Git |
| `docs/` | 调研、设计、使用指南、验收 JSON 与最终截图 | 纳入 Git，保留历史验证证据 |
| 根目录三个中文报告 | 初始需求、详细设计和项目计划的历史基线 | 保持原路径，保留既有文档链接 |
| `vendor/circuitjs/` | 固定上游源码归档与 GPL 许可证 | 纳入 Git，不受发布归档忽略规则影响 |
| `public/vendor/circuitjs/` | 固定内核运行资源与来源记录 | 纳入 Git；支持普通前端构建及本地使用 |
| `package.json`、`package-lock.json`、配置、许可证与启动脚本 | 依赖锁定、项目配置、许可和运行入口 | 纳入 Git |
| `releases/*.json` | 各版交付包 SHA-256、文件数和验收记录 | 纳入 Git，表示对应发布时快照 |
| `releases/*.zip`、`releases/*.tar.gz` | 打包交付物 | 保留本地，Git 忽略 |
| `dist/` | 前端生产构建输出 | 保留本地，Git 忽略 |
| `node_modules/`、`.engine-source/` | 安装依赖、内核构建时解压和注入的工作目录 | Git 忽略 |
| `output/`、`.playwright-cli/` | 浏览器临时截图、下载、日志、会话与调试输出 | Git 忽略；需长期保留的材料整理到 `docs/` |
| `.env*`、本地工具缓存、系统/编辑器临时文件 | 本机配置和临时数据 | Git 忽略；`.env.example` 和 `.env.*.example` 可纳入 |

运行所需的固定内核及其对应源码归档一起保留。忽略规则仅针对 `releases/` 中的交付归档，不使用全局 `*.gz` 或 `*.zip` 规则，避免误排除第三方源码和未来的测试资源。

## 从源码运行

```sh
npm ci
npm test
npm run build
npm start
```

构建需要先安装开发依赖；生成 `dist/` 后，本地启动服务本身不依赖前端构建工具。打开 `http://127.0.0.1:4173/`。使用包含 `dist/` 的 ZIP 交付包时，可直接执行 `npm start`。

需要重建内核时执行 `npm run build:engine`，随后执行 `npm run build`。修改内核应保留在覆盖文件或构建脚本中，不直接依赖 `.engine-source/` 的手工修改。

## 提交和发布

提交前检查 `git status` 和差异，确认没有依赖目录、临时浏览器数据或本机配置进入暂存区。涉及代码时运行对应检查；文件整理和文档变更不需要重新执行全部浏览器数值矩阵。

验收报告和交付校验清单属于对应版本的历史证据。后续文档或代码变化不会自动改写旧发布清单，也不应为了匹配当前工作区而修改旧包的 SHA-256。新增发布重新生成包和清单。

Git 提交与推送分开处理：本次整理只建立本地提交，不配置或推送远程仓库。
