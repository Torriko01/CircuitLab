## 能够区分的故障与测量要求

| 课 | 挑战 A | 挑战 B | 完整证据 |
|---|---|---|---|
| 按键 | τ=0.1 ms，反跳穿过，OUT 多次上升 | τ=10 ms，8 ms 按住未跨上门限 | 8 ms 同次 RAW 次数、OUT 次数、FILTER 峰值 |
| 运放 | 实际 2 倍但上限仅 1.6 V | 实际 1.6 倍，上限 2.8 V | 1 V 同次 VIN、VOUT、PLUS−FB，另加 0.4 V 的 VOUT |
| SPI | 2.2 kΩ/200 pF 数据较慢，上升沿接收 | 100 Ω/200 pF 数据较快，却与改变沿同侧接收 | 1 MHz 同次 DATA 上升、改变采样间隔、不保证事件数 |

所有必需证据的目的均为“区分候选原因”。评分核对测量种类、测点、运行、变体及条件；不接受仅一个异常值、错误目的或跨条件替代。运放规则额外要求三条标称证据确实来自 1 V，防止另一输入档位的输出补入标称链条。

典型实测：

| 情境 | 观测 | 工程解释 |
|---|---|---|
| 按键 A，8 ms | RAW=3，OUT=3，FILTER 接近 3.3 V | 反跳可完整跨门限，滤波不足 |
| 按键 B，8 ms | RAW=3，OUT=0，FILTER 峰值约 1.7552 V | 有效按键未达到 2.31 V 上门限 |
| 运放 A，1 V 输入 | VOUT≈1.60002 V，PLUS−FB≈0.19999 V | 输出受限，不能直接使用虚短 |
| 运放 B，1 V 输入 | VOUT≈1.599998 V，输入差分很小 | 线性反馈比例为约 1.6 倍 |
| 运放降到 0.4 V | A 输出约 0.8 V；B 约 0.64 V | 多档输入可区分饱和与比例 |
| SPI A，1 MHz | 上升约 372.81 ns，改变采样间隔约 500 ns，3 个不保证事件 | 半周期位置正常，数据在完整窗口内仍未充分建立 |
| SPI B，1 MHz | 上升约 16.95 ns，间隔约 0，3 个不保证事件 | 快边沿不能替代正确的采样位置 |
| SPI A，500 kHz | 本模型三个窗口恢复保证区域 | 降速为这一数据路径增加了有效时间 |
| SPI B，500 kHz | 仍有三个不保证事件 | 降速不自动修复采样沿重合 |

边沿交点由有限步长和线性插值观察；相对时间按约 2Δt 分辨。界面中的小数位和重合标记不表示仪器精度、真实零延时或实际抖动。SPI 的“通过/不保证”只针对指定教学窗口，不预测芯片的亚稳态概率或协议成败。

## 完整流程、迁移和生产验收

Chromium 与 WebKit 均实际完成六个挑战：先只保存不足证据提交，确认无法形成完整分析；再补齐要求，得到 8/8；随后完成两道迁移题，保存复盘并刷新恢复。WebKit 结果是自动化引擎交叉检查，不代表所有 Safari 版本已全量验收。

生产验收覆盖：

- schema 3 旧九课记录备份为 `-v3-backup` 后迁移至 schema 4，保留旧复盘、证据数值、原课程版本和关联 ID。
- schema 4 导出/导入往返；非法导入保持原数据；存储写入失败时内存学习、导出及恢复。
- 按键多计/漏计/延长按住，运放线性/饱和/缓冲，SPI 正常/慢边沿/降速/错沿的实际交互。
- 三个真实采样事件表、波形慢放、十二课首页，以及 1280/1440 px 桌面宽度无横向溢出。
- 阻断外部网络请求后仍可加载本地内核并求解；外部运行请求和页面异常均为 0。

截图已人工检查：[按键](./按键实验预览-v0.4.png)、[运放](./运放实验预览-v0.4.png)、[SPI](./SPI采样实验预览-v0.4.png)。运放反馈到地的支路已调整位置，避免与同相输入线交叉造成读图歧义，电气模型保持一致。随后对最终连线重新核验新三课矩阵。

单元检查还覆盖：初始高不计新边沿、窗口内部短扰动、空事件返回空值、错误测量类型/频率/按住时间、跨输入档位/运行、schema 1/2/3 迁移及当前字段缺失、参数合法性和半步长预算。

## 运行与复现

已有 `http://127.0.0.1:4173/` 页面刷新即可读取新构建；保持同一来源保留学习记录。交付包 `releases/电路直觉实验室-MVP-0.4.zip` 解压后运行 `npm start`，macOS 也可使用随附启动脚本。校验见 `releases/交付包校验-v0.4.json`。

开发执行 `npm test`、`npm run build`；开发服务 `/probe.html` 中运行 `verifySignals()`，原九课分别用 `verifyStages()`、`verifyExtensions()`、`verifyEngine()`。页面脚本为 `scripts/verify-signal-flows.js`，生产验收为 `scripts/verify-signal-production.js`，均使用隔离 Playwright CLI 会话。它们会重置测试会话数据，不应用于个人学习浏览器。
