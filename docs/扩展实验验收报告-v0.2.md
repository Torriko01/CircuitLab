## 2. 新增内容与学习目标

| 实验 | 引导内容 | 故障题需要区分的原因 | 工程迁移 |
|---|---|---|---|
| GPIO 的真实引脚 | 推挽、开漏、高阻、上下拉、有限驱动和负载移除 | 开漏释放缺上拉／推挽带载过重 | VOH/VOL 条件、接收门限、掉电反灌与引脚限制 |
| 供电瞬态与去耦 | 路径电阻、局部电容、短脉冲/持续电阻负载、最低值 | 路径电阻偏大／局部电容偏小 | 芯片端测量、触发、实际 BOR 与去耦连接 |
| ADC 的采样与参考 | 显式开关和保持电容、采样窗口、源阻抗、初始状态、参考 | 建立不足／参考与换算假设不一致 | 通道切换、采样周期、输入及参考范围、比率测量 |

贯穿测量新增：

- 分压电阻可达 1 MΩ，加入 1/10 MΩ 仪表输入模型，直接观察“测量也会加载电路”。
- I²C 加入 10/100 pF 探头电容，实际并入求解；图中 `CB_TOTAL` 为总电容。
- 供电课增加窗口最低值和观察线越界累计时间；ADC 增加事件对应的保持电压与理想数字码。
- 首页加入综合排查练习，串联三个子课的分析方法。它使用各自的已验证模型，没有声称完成整板联合仿真。

每课仍按认识任务 → 预测 → 实验 → 取证 → 判断 → 迁移 → 复盘执行。完成流程与独立掌握分别呈现。

## 3. 数值验证方法

### 3.1 覆盖范围

新增矩阵包括：

| 项目 | 覆盖 |
|---|---|
| GPIO 引导组合 | 5 种模式 × 3 种上拉 × 3 种负载 × 接入/移除，90 次捕获 |
| GPIO 诊断 | 两变体 × 接入/移除，4 次捕获 |
| 供电引导组合 | 3 种路径电阻 × 3 种电容 × 3 种负载 × 3 种导通时间，81 次捕获 |
| 供电诊断 | 两变体 × 短脉冲/持续导通，4 次捕获 |
| ADC 引导组合 | 3 种源电阻 × 2 种电容 × 4 种窗口 × 3 种参考 × 2 种初始状态，144 次捕获 |
| ADC 诊断 | 两变体 × 5/20 µs 窗口，4 次捕获 |
| 步长收敛 | 供电与 ADC 共 6 个敏感/故障配置，各进行标准与半步长捕获，12 次 |
| 仪表与探头 | 分压 3 种仪表，I²C 3 种探头电容，6 次 |

总计 345 次。诊断时的测试上拉作为探索操作允许使用；矩阵的 GPIO 诊断检查针对必需的“无测试上拉”隔离操作。新课的非电气字段保持默认，矩阵不声称覆盖任意参数输入。

### 3.2 独立参考与容差

| 量 | 参考与检查 | 主要容差 |
|---|---|---|
| GPIO 电位 | 节点电导收支；核对多支路 KCL | 引导电位 1 µV，诊断电位 10 nV；KCL 10 nA |
| 供电瞬态 | 电阻负载下的最终分压、导通/恢复两段指数响应；指定时刻、最低值和 KCL | 电压 6 mV，KCL 2 µA |
| ADC 保持电压 | `(Rsource+100 Ω)×C` 的独立建立公式，覆盖高/低初始状态 | 4 mV |
| ADC 保持阶段 | 开关断开完整步与捕获结束的电压差 | 10 µV |
| ADC 数字码 | 独立解析电压推导的码，允许电压数值误差对应的码差 | 按 4 mV 换算并加 1 码；算法边界另有精确单元检查 |
| ADC 实际参考 | 与独立电压源设置对照 | 10 nV |
| 收敛 | 同一配置减半步长，比较实际最低值/保持值 | 供电 6 mV，ADC 2 mV |
| 仪表负载 | 独立并联分压公式 | 10 µV |
| 探头电容 | 30%–70% 一阶边沿 `ln(7/3)×RP×Ctotal` | 10 ns |

这些容差针对受限教学模型。尤其 ADC 的数值验收不是“12 位精度认证”：本版目标是判断建立不足、比例误差和测量条件，不能据此比较亚 LSB 级真实器件性能。课程边界已明确提示。

实际预设矩阵中，ADC 保持电压对独立解析参考的最大绝对差约 **2.02 mV**；供电指定时刻电压最大差约 **1.89 mV**，均在相应容差内。原始每项实际值、参考值与容差在 JSON 中保留。

### 3.3 有代表性的实际结果

| 配置 | 实际结果 | 支持的结论 |
|---|---:|---|
| GPIO 推挽高，25 Ω 负载 | PIN≈1.64998 V | 有限输出电阻会带来显著带载压降 |
| 同一 GPIO 移除负载 | PIN≈3.29992 V | 受控移除能区分负载影响 |
| GPIO 开漏释放、无上拉、移除负载 | PIN≈6.60 µV | 显式漏电模型下趋向低位；不代表真实悬空的唯一表现 |
| 供电诊断 A，持续负载 | VMCU≈2.65305 V | 路径偏大造成长期压降 |
| 供电诊断 B，持续负载 | VMCU≈3.14651 V | 长期压降符合 2 Ω 路径，需结合短时过程识别电容差异 |
| ADC 诊断 A，5 µs | HOLD≈1.51456 V | 高源阻抗造成建立不足 |
| 同一 ADC 诊断 A，20 µs | HOLD≈1.64992 V | 延长窗口显著减小建立误差 |
| ADC 诊断 B，5/20 µs | HOLD≈1.65000 V，VREF=3.6 V | 保持正常而换算偏低，参考比例问题仍存在 |
| 1 MΩ 分压接 1 MΩ 表 | VOUT≈1.10000 V | 高阻测量对象可能被仪表显著加载 |
| 1 MΩ 分压接 10 MΩ 表 | VOUT≈1.57143 V | 更高输入阻抗减小加载，但仍非理想开路 |
| I²C 原 100 pF 加 100 pF 探头、100 kHz | tr≈796.46 ns | 探头电容可使本模型上升时间约翻倍 |

### 3.4 验证中发现并修正的问题

初轮检查发现：在控制信号刚下降的仿真步，模拟开关仍存在状态更新时间差；若直接把该步当作最终保持值，会显示约毫伏级的假性“保持漂移”。

处理方式是取断开后的首个完整求解步，保留真实取样时刻；未形成完整事件则不给出保持值。随后重跑完整矩阵，保持稳定性检查通过，并检查步长减半。没有通过放宽保持漂移容差来掩盖这一问题。

图上标签也经实际截图检查，调整了节点与器件标注位置，避免与元件值重叠；这些调整不改变电气连接。

## 4. 正确结论需要足够证据

六个新增诊断变体都进行了两条路径测试：先故意保存不足证据提交，再补齐测量。

| 课程 | 不足的证据 | 获得完整取证评价的要求 |
|---|---|---|
| GPIO | 只测带载 PIN | 正常 VDD＋移除负载、无测试上拉时的 PIN |
| 供电 | 只保存短脉冲最低值 | 正常 VIN＋300 µs 或持续负载时的 VMCU 最低值 |
| ADC | 只保存一个窗口的 HOLD 或数字码 | VIN＋VREF＋5 µs、20 µs 两个结束事件的保持电压 |

生产包中六个变体均满足：不足证据时显示“继续完善证据链”；完整证据、正确解释及行动可达 8/8。判分仍是结构化规则，不声称理解任意自由文本。

新增六道迁移题通过实际页面作答，三课复盘保存并刷新恢复均通过。检查使用隔离测试浏览器，不操作用户个人学习记录。

## 6. 工程实践的有效范围

三课都附有真实工程检查点与官方资料入口。它们强调：

1. 引脚、电平、供电、参考和采样约束来自目标器件的保证条件。
2. 测量必须说明端点与时刻，仪表和探头也可能加载电路。
3. 修复后需要同条件复测，不能把“改参数后没再出错”直接当成唯一原因证明。
4. 单故障模型用来建立分析方法；实物可能有公共地阻抗、布局寄生、器件差异或多个问题并存。

本版没有执行实物电气实验，也没有测量个人学习收益。供电课未建模 ESR/ESL、稳压器环路、启动或真实 BOR；GPIO 不预测限流/损坏；ADC 不模拟完整 SAR、INL/DNL、噪声或校准。不能把本次教学验证说成实物硬件已验证合格。

MOSFET、感性负载和完整 PCB 对比属于调研中的第二批，本版未加入。

## 7. 运行与复查

`npm start` 后访问 `http://127.0.0.1:4173/`。已有服务若运行于本目录，刷新页面即可读取新构建。长期学习保持同一端口，避免浏览器记录分散到不同来源。

开发核验：

```sh
npm test
npm run build
npm run dev
```

在开发核验页 `/probe.html` 执行 `await verifyEngine()` 和 `await verifyExtensions()`，可分别复现两套数值矩阵。保持该页活动，避免捕获被后台行为中断。

完整页面流程可用 Playwright CLI 在隔离测试会话中运行 `scripts/verify-browser-flows.js`。脚本会重置该会话的新增课程进度；不要用于个人学习浏览器。
