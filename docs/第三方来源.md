- 补本地空侧栏资源、内嵌 favicon，过滤不合法中文翻译条目，补常用属性标题，纠正将 wire loop 误译为“线圈”的提示。原生 Esc/工具栏状态和纯布局撤销由沙盒桥接适配。
- 上述修改均由 `scripts/build-engine.mjs` 和桥接覆盖文件重现；`provenance.json` 记录归档 SHA-256、变更摘要及桥接 SHA-256。没有直接依赖 `.engine-source` 的临时手工改动。
- 本项目原理图模板、课程、中文说明、评分、绘图与本地服务为本次新增实现。

原始归档包含完整对应源代码、上游许可声明及 TypeScript 移植相关文件。上游 `ts/package.json` 的泛用许可字段并不替代各源文件的 GPL 声明；本项目按源文件和仓库许可证保留 GPL 通知。

## 前端依赖

React、React DOM、scheduler、lz-string 等具体版本固定在 `package-lock.json`。第三方许可文本汇集于 `THIRD_PARTY_NOTICES.txt`。构建工具与测试工具为开发依赖，不是运行本地静态页面所必需的服务。

## 教学依据

I²C 上拉选型与 30%–70% 上升时间参考 [TI SLVA689](https://www.ti.com/lit/an/slva689/slva689.pdf)。课程电路与图示自行制作；模型约束在页面中单独声明。未打包厂商手册，也未将教学等效开关称为特定器件模型。
