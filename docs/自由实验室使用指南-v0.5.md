# 自由实验室使用指南

打开 [本地实验室](http://127.0.0.1:4173/)，点击左侧“自由实验室”。如果服务未启动，在项目目录执行 `npm start`，或双击 macOS `启动实验室.command`。

使用 Git 检出的源码时，先按 [README](../README.md) 执行 `npm ci` 和 `npm run build`，再启动；ZIP 交付包已包含运行构建。

## 先完成一个五分钟回路

1. 选择“＋ 分压与负载”，先预测：3.3 V 输入、两只 10 kΩ 电阻，空载输出是多少？
2. 点击“运行 / 继续”，将鼠标放到电阻上，查看原生读数；输出支路应约 1.65 V、165 µA。读数的正负取决于元件两端顺序。
3. 点击负载支路开关，输出应降到约 1.10 V。开关是运行中的输入，不会把时间清零；同一条曲线上已包含两种开关条件。
4. 暂停，右键 R1 选择编辑，改为 20 kΩ；工作台会要求重新开始。负载仍接入时，输出应约 0.66 V。
5. 在“观察与下一步”写下原因，等待“已保存到本机”，再点击“下载项目”。重新打开项目后从 t=0 暂停，点击运行重新验证。

这个练习建立“上游电阻的压降由下游总取流决定”的感觉。换一组阻值再做一次，区分分压比例和带载能力。

## 从空白画布绘制

选择“＋ 空白电路”。用工具栏或“绘制”菜单添加直流电压源、两只电阻、导线和地；拖动确定两端，设置参数，按 Esc 回到选择模式。连接必须落在同一个网格端点，图形看起来接近并不一定已连接。选中后拖动稍停再移动，原生编辑器有约 150 ms 防误触延迟。

例如画 3.3 V 电源 → 10 kΩ → 输出节点 → 10 kΩ → 电源负端，再把负端接到地。电阻可以输入 `10k`；电容可输入 `1u`，注意单位与数量级。所有支路必须有合理返回路径。

右键元件可编辑、删除、复制或选择“在新示波器中查看”。示波器配置会保存，历史曲线不保存。需要节点对地电压时先明确参考地；元件两端电压不一定等于其任意一端对地电压。同名节点标签会把节点电气连接，请用普通文字写不希望影响连接的说明。

## 运行和保存

| 操作 | 结果 |
|---|---|
| 暂停后继续 | 保留当前时间、电容电压、电感电流 |
| 改值、增删、重连 | 暂停，要求重新开始；旧曲线不再用来解释新设计 |
| 切换开关 | 作为同次运行的激励，可连续观察 |
| 平移视图、改文字或纯布局撤销 | 保留电气状态；若移动改变连接，则属于改图 |
| 重新开始 | t=0，采用显式初始条件和当前开关位置 |
| 隐藏页面、离开或切项目 | 暂停，保存已完成的修改；回来不自动运行 |
| 关闭后重开 | 恢复设计、笔记和示波器配置，从 t=0 暂停 |

本机项目库与课程学习记录分开。“下载项目”导出 `.circuit.json`，含设计、笔记和版本；“导出原生 XML”只带电路及示波器配置，便于原生工具检查。“导入文件”或“粘贴电路文本”支持本项目 JSON、当前内核 XML 和已验证的旧文本完整电路，导入会创建独立副本。

不同浏览器、端口以及 `localhost`/`127.0.0.1` 的本机库互不共享。固定使用一个地址，并定期下载文件；自动保存不能替代文件备份。存储失败时仍可编辑和下载；若出现多窗口冲突，先下载或另存新项目，再决定是否载入磁盘版本。

## 培养工程判断的三个小练习

| 起步电路 | 只改一个条件 | 观察与解释 |
|---|---|---|
| 分压 | 电阻同倍增大，再接负载 | 空载比例可以不变，带载误差却会变 |
| RC | 电容增加，再给短脉冲 | 建立变慢；滤掉毛刺也可能错过有效输入 |
| 开漏 | 增大上拉电阻或总电容 | 释放边沿变慢；减小电阻又提高拉低电流 |

先说出预期，再测量；异常时依次检查电源、参考地、回路、连接、元件值、时间尺度和模型。错误提示只是定位线索。没有报错、波形看起来顺滑，都不足以证明真实电路符合器件手册。

本版面向小型教学与局部等效电路：运行 1–200 图元，每段连续运行 60 秒后暂停，可继续。重点验收的器件和模型边界见[验收报告](./沙盒验收报告-v0.5.md)。
