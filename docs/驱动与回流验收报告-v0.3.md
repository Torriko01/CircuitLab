## 实验范围

| 实验 | 可以操作和观察 | 两类故障 | 迁移方法 |
|---|---|---|---|
| MOSFET | 栅极、源极参考、路径阻抗、负载；真实非线性工作点与直流功耗 | 栅源驱动不足 / 供电路径压降 | 按压降定位，查目标栅压下的保证值 |
| 感性负载 | R/L、导通时间、普通续流或更高吸收电压；独立电流图、峰值、10% 时间 | 普通续流失效后高压备用吸收介入 / 普通续流与释放要求不匹配 | 同看应力、储能、衰减与器件额定 |
| PCB 回流 | 预制共用/独立返回、路径电阻、负载与本地信号注入 | 共用回流导致地抬升 / 传感器本地输出变化 | 同时测本地信号、参考地差和 MCU 端电压 |

首页综合排查增加驱动、关断与回流入口，与供电、采样、GPIO 共六个子实验连接。各课仍是独立模型，未声称整板联合仿真。

### 参考、容差与结果

| 检查量 | 独立参考 | 验收容差 |
|---|---|---|
| MOSFET 电流、VDS | 平方律与负载线交点，二分求解 | 2 µA、0.2 mV |
| MOSFET KVL、KCL | 整条路径压差、电流收支 | 0.1 µV、1 nA |
| 线圈关断前电流 | RL 阶跃解析式，含 1 Ω 开关 | 0.3 mA |
| 开关峰值 | VIN＋理想吸收电压＋非线性 Vf(I) | 25 mV |
| 电流 10% 时间 | 独立积分 `∫L dI/(RI+Vclamp+Vf(I))` | 3 µs |
| 线圈能量 | 初末 ½LI² 与电阻、二极管、吸收源的积分收支 | 相对残差 0.8% |
| 关断平台 KCL | 线圈、二极管与关闭开关电流收支 | 50 µA |
| 回流电位 | 含 1 GΩ 输入的节点方程 | 0.1 µV |
| 本地源及三电压叠加 | 源设置与端点恒等式 | 1 nV、1 pV |
| 步长减半 | 对比工作点/平台、峰值与事件时间 | 静态/平台 10 µV；峰值 20 mV；10% 时间 2 µs |

本轮实际：58 个续流配置的峰值参考最大差约 **1.004 mV**，10% 时间参考最大差约 **0.250 µs**，能量最大相对残差约 **0.00554%**。这些差异是本模型与离散求解的表现，不能当作仪器或实物误差指标。

典型观测：

| 情境 | 实际观测 | 支持的解释 |
|---|---|---|
| 默认 MOSFET，3.3 V 栅源、100 Ω 负载 | I≈117.469 mA，VDS≈0.135631 V | 大部分电压落在负载上 |
| 栅源仅 1.8 V，100 Ω 负载 | I≈22.5 mA，VDS≈9.73 V | 沟道压降明显，驱动不足 |
| 普通续流、100 Ω/20 mH、导通 1 ms | SW 峰值≈12.59044 V，10% 时间≈396.493 µs | 低应力、较慢电气衰减 |
| 额外 24 V 吸收，同一线圈与导通时间 | SW 峰值≈36.59031 V，10% 时间≈68.895 µs | 更快衰减、更高开关应力 |
| 共用 1 Ω 回流，40 Ω 负载 | 本地 1.65 V，地差≈0.11905 V，MCU≈1.76905 V | 参考地移动而非信号源本身变化 |
| 独立返回同一参考点 | 地差≈0，MCU≈1.65 V；负载段压降仍存在 | 本模型中解除敏感参考与负载段的共用 |

时间测量遵守固定内核的状态时序：CTRL 下降后的首个完整断开求解步作为衰减起点，交点插值；不以控制边沿的过渡步冒充完全断开。无完整事件时返回空值与原因。

## 诊断评价与工程结论

| 课 | 满分证据链 | 不能获得完整证据分的情况 |
|---|---|---|
| MOSFET | 同次捕获的 GATE−SOURCE、DRAIN−SOURCE、VIN−VLOAD | 仅测栅极对地、单个低电流、跨运行拼接 |
| 续流 | 同次捕获的正常 VIN、SW 峰值、10% 时间 | 只测峰值、选错峰值节点、未形成事件 |
| 回流 | 负载接入、150–350 µs 平台、同次同游标的 SIG−SGND、SGND−GND、SIG−GND | 负载移除、静默后段、跨运行/时刻拼接 |

三项证据的测量目的均需为“区分候选原因”。评分是结构化规则，配合预制单故障场景，不表示能理解任意自由文本或识别所有实物故障。

Chromium 与 WebKit 都实际完成：先用不足证据提交，再补齐证据获得 8/8；完成两道迁移题；保存复盘并刷新恢复。单元检查另验证跨挑战、错误目的、事件缺失、PCB 非平台测量不会被当作完整链条。

## 有效范围

MOSFET 是教学平方律模型，不模拟温升、栅电荷、PWM 损耗和实际器件 SOA；续流支路的理想吸收源不是真实 TVS，10% 电流时间不等于机械释放；PCB 是集中电阻与预制接法，无电磁场、寄生电感或 EMC 验证。独立返回示例不能变成“一律割地”的规则。

已附官方器件手册与应用资料入口。完整方程、故障定义、测量规则及实物检查点见 [模型及工程实践说明](./驱动与回流模型及工程实践-v0.3.md)。没有执行实物实验，也没有测量个人学习收益。

## 运行和复现

已有本地服务 `http://127.0.0.1:4173/` 可刷新读取新构建；固定使用同一浏览器和端口保留学习记录。解压交付包后运行 `npm start`，也可使用随附 macOS 启动脚本。

开发：`npm test`、`npm run build`。启动开发服务，在 `/probe.html` 执行 `verifyStages()`、`verifyExtensions()`、`verifyEngine()`，分别复现三套矩阵。开发探针不作为生产入口。

浏览器：Playwright CLI `run-code --filename scripts/verify-stage-flows.js` 复现三课完整流程；生产服务器使用 `scripts/verify-stage-production.js`。脚本会重置隔离测试会话的记录，不应用于个人学习浏览器。

交付包：`releases/电路直觉实验室-MVP-0.3.zip`；源码、构建产物、原始内核归档、许可证、说明与验收数据均保留。SHA-256、CRC 与源码哈希见 `releases/交付包校验-v0.3.json`。
